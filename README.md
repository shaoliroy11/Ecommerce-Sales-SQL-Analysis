# Ecommerce-Sales-SQL-Analysis
SQL-based analysis of e-commerce sales, customers, products and operational performance using MySQL.

## Project Overview

This project analyzes an e-commerce sales dataset using MySQL to identify
sales trends, customer behavior, product performance and operational issues.

## Business Objectives

- Analyze overall sales performance
- Identify high-performing products and categories
- Compare regional performance
- Understand customer purchasing behavior
- Analyze cancellations and returns
- Evaluate delivery performance
- Identify trends that can support business decision-making

## Dataset

- 10,020 raw records
- 15 columns
- Order, customer, product, sales and operational information

## Tools Used

- MySQL
- MySQL Workbench
- Microsoft Excel
- GitHub

## SQL Skills Demonstrated

- Data cleaning
- Data quality checks
- Aggregation
- GROUP BY
- Subqueries
- Views
- KPI calculations

### Sales Performance
